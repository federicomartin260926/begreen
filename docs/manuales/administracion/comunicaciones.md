# Comunicaciones y documentos compartidos

Abre **Administración → Comunicaciones** para mantener documentos globales descargables. No son documentos privados de un proyecto ni envían avisos a destinatarios.

## Listado y descarga

La tabla muestra nombre original, descripción, fecha de subida y acciones. Pulsa descarga para obtener el archivo con su nombre original.

## Subir un documento {toc}

Condición previa: revisa que el archivo esté aprobado y no contenga datos personales ni información de otro cliente.

1. Pulsa **Subir documento**.
2. Selecciona PDF, DOC, DOCX, XLS o XLSX, con un máximo de 5 MB.
3. Añade una descripción útil.
4. Guarda y comprueba nombre, descripción y fecha en el listado.
5. Pulsa descarga y abre el archivo para confirmar que es la versión correcta.

## Editar, sustituir o borrar

En edición puedes cambiar la descripción sin reemplazar el archivo. Si eliges uno nuevo, el sistema guarda el reemplazo y elimina el anterior. La papelera solicita confirmación y elimina tanto el registro como el archivo; no hay papelera de recuperación.

Los documentos son globales, no están dirigidos a destinatarios seleccionados ni ligados automáticamente a un proyecto. El módulo no envía correos ni notificaciones. Revisa que el archivo no contenga datos personales o información de otro cliente antes de publicarlo.

Si sustituyes un archivo, descarga la nueva versión después de guardar. No existe papelera de recuperación; conserva el original fuera de la plataforma antes de borrar.
