# Configuración editorial de IA

Administración → IA está reservada al Super Administrador. Configura el proveedor/modelo efectivo y las instrucciones editoriales usadas en narrativas del Plan.

## Qué puede modificarse

La parte técnica muestra OpenAI y Anthropic, con los modelos asociados. Un proveedor sin credenciales disponibles queda deshabilitado. Las credenciales, URLs, timeouts y límites no se editan en esta pantalla.

La parte editorial contiene seis bloques: Generales, Resumen ejecutivo, Categorías, Próxima edición, Evitar y Cierre final.

## Actualizar instrucciones

Condición previa: dispone de un texto editorial aprobado y autorización para usar el proveedor cuando se haga una prueba.

1. Revisa proveedor y modelo disponibles.
2. Edita únicamente reglas de estilo, tono y estructura editorial.
3. Guarda con **Actualizar** y confirma el mensaje.
4. Vuelve a abrir la pantalla y comprueba que el texto y el modelo seleccionados se mantienen.
5. Genera después un informe de prueba solo cuando exista autorización para usar el proveedor.

Las reglas editoriales no pueden cambiar cálculos, estados, categorías, contrato JSON ni datos autorizados. No solicites a la IA que invente métricas o complete información ausente.

## Restaurar valores

Si aparece **Restaurar reglas por defecto**, la acción requiere confirmación y sustituye los seis bloques editoriales. No cambia el proveedor ni los modelos. Úsala solo si realmente quieres perder las reglas personalizadas actuales.
