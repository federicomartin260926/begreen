# Tablas auxiliares

Administración → Tablas auxiliares mantiene catálogos globales relacionados con medidas, protocolos y exportaciones. El menú lo presenta al Super Administrador.

## Catálogos disponibles

La pantalla ofrece Protocolos, Categorías GHG, Categorías, Departamentos, ODS, ESG, Scope, Áreas de impacto, Fuentes de verificación y Bloques de medidas.

## Procedimiento común

Condición previa: identifica el catálogo correcto y revisa si el elemento ya existe. Estos datos son globales y pueden aparecer en Medidas, Planes o exportaciones.

1. Abre el tipo de tabla.
2. Revisa el listado y su orden.
3. Pulsa **Nuevo** para añadir o el lápiz para editar.
4. Completa nombre, código, descripción, orden o traducciones según el tipo.
5. Guarda y confirma el mensaje de creación o actualización.
6. Localiza el elemento en el listado y vuelve a abrirlo para comprobar sus relaciones.

Los campos cambian según el catálogo. Protocolos incluyen tipo de proyecto y criterio de agrupación. Los bloques se vinculan a un protocolo, tienen código único dentro de él, orden, estado activo y una posible pregunta previa. Algunas entidades admiten textos ES/EN.

## Restricciones

Las categorías protegidas no pueden borrarse y algunos campos quedan bloqueados al editar. Si un elemento está en uso, la aplicación puede impedir la eliminación y mostrar un aviso. No cambies códigos o relaciones para corregir un problema aislado sin revisar su impacto en Medidas y Planes.

Para borrar, usa la papelera únicamente después de confirmar que el elemento no se utiliza. Si la aplicación rechaza la acción, conserva el registro y revisa sus dependencias; no lo sustituyas por otro de nombre parecido.
