# Navegación y Dashboard

## Estructura de la pantalla

La barra lateral da acceso a **Proyectos** y a los módulos del proyecto activo. La cabecera contiene el selector de idioma y el menú personal. En pantallas estrechas, abre el control del menú para desplegar la navegación.

Antes de registrar información, comprueba qué proyecto está activo. Esta precaución evita añadir medidas, desplazamientos o documentos al proyecto equivocado.

## Dashboard de proyectos

La pantalla **Proyectos** reúne filtros, ordenación, métricas y tarjetas. Puedes buscar por nombre, país, creador y fechas, y ordenar por fecha o nombre. Usa **Limpiar filtros** si un proyecto conocido no aparece.

Cada tarjeta resume el avance de las ocho fases. Los estados ayudan a orientarse, pero no sustituyen la revisión del contenido de cada módulo. Algunas fases están representadas para mostrar el recorrido completo aunque todavía no ofrezcan un flujo operativo.

## Seleccionar un proyecto

1. Localiza el proyecto con los filtros del Dashboard.
2. Abre **Acciones del proyecto** y pulsa **Seleccionar proyecto**.
3. Comprueba que el nombre mostrado en el selector lateral es el correcto.
4. Abre el módulo con el que vas a trabajar.

El proyecto queda activo durante la sesión. Los módulos de Plan, BGoS, Implementación, Calculadora e Informe Final utilizan ese contexto. Si no hay ninguno seleccionado, la aplicación te devuelve al Dashboard.

## Comprobar el avance

Cada tarjeta presenta las ocho fases y un botón cuando el recorrido está disponible. Después de guardar en un módulo, vuelve a **Proyectos** o utiliza la barra lateral para continuar con la fase siguiente. Los estados de la tarjeta son una orientación: para comprobar un resultado, entra en el módulo y revisa el dato guardado.
