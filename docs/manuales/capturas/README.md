# Capturas del manual

Directorio reservado para capturas reales obtenidas en DEV. La Iteración 3 no incorpora imágenes porque no hay archivos de producto con procedencia, fecha y anonimización comprobables. La lista exacta de pantallas pendientes está en `interno/matriz-qa.md`.

Cada captura futura debe indicar pantalla, rol, fecha de validación y capítulo consumidor. No se usarán wireframes ni composiciones ficticias como evidencia del producto actual.

Sintaxis admitida por el generador:

`![Descripción accesible](capturas/nombre-seguro.png)`

Política:

- Solo PNG o JPEG reales obtenidos en LOCAL/DEV.
- Recortar u ocultar correo, teléfono, nombres de personas, tokens e identificadores no autorizados.
- No usar datos de otro proyecto o cliente sin autorización.
- Guardar dentro de `docs/manuales/capturas/`; el generador rechaza rutas absolutas, `..` y recursos remotos.
- Registrar en la matriz interna el rol y la fecha de comprobación.
